Cifra documenti e prenotazioni

Per aggiungere un PDF al sito senza renderlo pubblico. Tutto avviene qui nel browser e niente viene inviato.

  1. Inserisci la password del viaggio e scegli uno o più PDF, oppure Documenti/privato.json se hai cambiato le prenotazioni.
  2. Nei Download trovi i file .enc: spostali in Australia/Documenti_cifrati/, sostituendo quelli vecchi.
  3. Tieni l'originale in Australia/Documenti/ (non va su GitHub). Se è un PDF nuovo, aggiungilo a HUB_DOCS in hub/hub-geo.js.
  4. Carica su GitHub i file .enc (e hub-geo.js se l'hai modificato).
